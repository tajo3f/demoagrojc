# Agropecuária JC — Site Institucional

Projeto estático multipágina criado para apresentação e publicação da Agropecuária JC, em Conceição do Castelo - ES.

## Páginas
- `index.html` — Início
- `sobre.html` — A Agropecuária
- `solucoes.html` — Produtos & soluções
- `avaliacoes.html` — Avaliações
- `contato.html` — Contato e mapa
- `privacidade.html` — Política de Privacidade
- `404.html` — Página de erro

## Stack
HTML5 semântico, CSS3 e JavaScript Vanilla. Sem React, Next.js, banco de dados ou dependências de build.

## Antes da publicação definitiva
1. Definir o domínio final.
2. Atualizar `canonical`, Open Graph e criar `sitemap.xml` com URLs absolutas.
3. Confirmar se existe atendimento aos sábados antes de publicá-lo.
4. Confirmar qualquer categoria de produto mais específica antes de adicioná-la.
5. Se forem adicionados analytics, Meta Pixel ou formulários, atualizar a Política de Privacidade.

## Publicação
Pode ser publicado diretamente na Vercel, Netlify, Cloudflare Pages, GitHub Pages ou hospedagem convencional.

Na Vercel, arraste a pasta ou conecte o repositório. O `vercel.json` já contém cache de assets e cabeçalhos básicos.

## Edição
- Cores e design system: `assets/css/style.css` em `:root`
- Interações e efeitos: `assets/js/main.js`
- Imagens: `assets/images/`
- Ícones: `assets/icons/sprite.svg`
